# Security reporting

Do not post a working exploit, private key, pairing token or account credentials
in a public issue. Use the repository's private vulnerability reporting feature
when it is enabled by the operator. If it is unavailable, request a private
contact without publishing the details. Hosting credentials and platform code
are deliberately absent from this repository.

Use current releases. No release claims immunity to remote code execution or
other vulnerabilities. Security-sensitive changes need regression tests and
review before release.
